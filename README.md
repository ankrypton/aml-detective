AML Detective

Work a real anti-money-laundering alert queue inside the Airflow UI.

A DAG runs a transaction-monitoring pipeline over synthetic bank activity. Its rules engine
raises alerts, and an Airflow 3.1 React plugin turns those alerts into case files you
investigate. Read the customer profile, follow the money on the flow graph, highlight the
transactions behind each rule, then close the alert or escalate it with a SAR. The server
grades you against the answer key, and a missed SAR costs the most, just like in real life.
